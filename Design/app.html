Data & backup

Florin holds one SQLite file. You can copy it, export it, import a backup, or — if you really want to start fresh — wipe everything.

Database location

Your data lives at ~/Library/Application Support/Florin/florin.db — 248 KB, last modified just now.

Export

Save a snapshot of every month, expense and savings goal as JSON or a printable PDF report.

Import

Bring in a previous Florin backup, or import a password-protected .xlsx budget file.

Reset all data

Permanently delete every month, expense and savings record. This cannot be undone — Florin will offer to make a backup first.
